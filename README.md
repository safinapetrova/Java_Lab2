# Задание 2

## Задача 2.1. Линия (Прямая)

### Текст задачи
Создайте сущность Линия, расположенную на двумерной плоскости, которая описывается:
- Координата начала: Точка
- Координата конца: Точка

Для указания координат нужно использовать сущность Точка, разработанную в задании 1.1. Создайте линии со следующими характеристиками:

2. Линия 2, горизонтальная, на высоте 10, от точки 5 до точки 25.
3. Линия 3, которая начинается всегда там же, где начинается линия 1, и заканчивается всегда там же, где заканчивается линия 2. Таким образом, если положение первой или второй линии меняется, то меняется и третья линия.

После создания всех трех объектов измените координаты первой и второй линий, причем сделайте это таким образом, чтобы положение третьей линии соответствовало требованиям пункта 3.
Измените координаты первой линии так, чтобы при этом не изменились координаты третьей линии.

- `start` (Point) — точка начала линии
- `end` (Point) — точка конца линии

Конструктор принимает два объекта `Point`. Метод `toString()` возвращает строку "Линия от{X1;Y1} до{X2;Y2}". Есть геттеры и сеттеры.

4. Вывести все три линии.
5. Изменить координаты начала Линии 1 и конца Линии 2 через методы `setX()` и `setY()`.

7. Создать новый объект `Point` и присвоить его началу Линии 1 через `setStart()`.

# Задание 3

## Задача 3.1. Студент

### Текст задачи
Создайте сущность Студент, которая описывается:
- Имя: строка
- Оценки: массив целых чисел.
- Может возвращать текстовое представление вида `Имя: [оценка1, оценка2,…,оценкаN]`.

Необходимо выполнить следующие задачи:
1. Создать студента Васю с оценками: 3,4,5.
2. Создать студента Петю и скопировать оценки Васи, присвоив содержимое поля с оценками Васи полю с оценками Пети.
3. Заменить первую оценку Пети на число 5. Вывести на экран строковое представление Васи и Пети. Объяснить результат.
4. Создать студента Андрея и скопировать ему оценки Васи так, чтобы изменение оценок Васи не влияло на Андрея.

### Класс `Student`
Свойства:
- `name (String)` — имя студента
- `grades (int[])` — массив оценок

Единственный конструктор с varargs: `Student(String name, int... grades)`. Если оценки не переданы или передан `null`, создаётся пустой массив. Метод `toString()` возвращает строку "Имя: [оценка1, оценка2, ...]". Есть геттеры и сеттеры.

### Алгоритм метода `task3_1`
1. Считать имя и оценки для Васи.
2. Создать объект `Student` для Васи.
3. Считать имя для Пети, создать объект и скопировать ссылку на массив оценок Васи.
4. Спросить у пользователя, на какое число заменить первую оценку Пети.
5. Изменить оценку и вывести обоих студентов — оценки Васи тоже изменятся.
6. Считать имя для Андрея, создать объект и скопировать массив оценок Васи через `Arrays.copyOf()`.
7. Спросить у пользователя, на какое число изменить первую оценку Васи.
8. Изменить оценку и вывести обоих студентов — оценки Андрея не изменятся. 

### Замечание о поверхностной и глубокой копии

При присваивании массива (`petya.setGrades(vasya.getGrades())`) копируется не сам массив, а ссылка на него. Петя и Вася ссылаются на один и тот же массив в памяти, поэтому изменение у одного влияет на другого.

При использовании `Arrays.copyOf()` создаётся новый массив с теми же значениями. Андрей получает независимую копию, и изменения Васи на него не влияют.

# Задание 5

## Задача 5.6. Студент отличник

### Текст задачи
Измените сущность Студент из задачи 4.7. Новые требования включают:
- Студент может возвращать значение своей средней оценки (вещественное число). Если оценок нет, то среднее – 0.
- Студент может возвращать информацию о том, является ли он отличником или нет.
- Студент является отличником если у него есть хотя бы одна оценка и все оценки только отличные.

Необходимо выполнить следующие задачи:
1. Создайте студента Васю с оценками 3,4,5,4
2. Создайте студента Петю с оценками 5,5,5,5
3. Выведите для обоих студентов информацию о среднем балле и являются ли они отличниками.

### Класс `Student` (дополнение к классу из задачи 3.1)
Свойства:
- `name` (String) — имя студента
- `grades` (int[]) — массив оценок

Конструктор: Student(String name, int... grades) — принимает имя и любое количество оценок.

Методы:
`getAverage()` — суммирует все оценки и делит на их количество. Если массив пуст, возвращает 0.
`isExcellent()` — проверяет, есть ли хотя бы одна оценка, и проходит по всем оценкам. Если найдена оценка не равная 5, возвращает `false`. Если все оценки равны 5, возвращает `true`.

### Алгоритм метода `task5_6`
1. Считать имя и оценки для Васи.
2. Создать объект `Student`.
3. Вывести имя, оценки, средний балл и статус отличника.
4. Считать имя и оценки для Пети.
5. Создать объект `Student`.
6. Вывести имя, оценки, средний балл и статус отличника.

### Вспомогательные методы ввода

В классе Main реализованы вспомогательные методы для безопасного ввода данных:
- `readString()` — считывает непустую строку.
- `readInt()` — считывает целое число с проверкой.
- `readDouble()` — считывает вещественное число с проверкой.
- `readGrades()` — считывает количество оценок и сами оценки (от 2 до 5) с проверкой.
- `readPoint()` — считывает координаты точки.
- `readStudent()` — считывает имя и оценки студента.

Все методы циклически запрашивают ввод до тех пор, пока пользователь не введёт корректное значение.

### Обработка ошибок

| Ситуация | Реакция программы |
| --- | --- |
| Пустой ввод | Сообщение об ошибке, повторный запрос |
| Ввод букв вместо числа  | Сообщение об ошибке, повторный запрос |
| Оценка вне диапазона 2-5 | Сообщение об ошибке, повторный запрос |
| Отрицательное количество оценок | Сообщение об ошибке, повторный запрос |
| 0 оценок у студента в задании 3.1 | Сообщение "У студента нет оценок, менять нечего!" |

### Особенности реализации
1. Форматирование чисел: метод `formatNumber()` в классе `Point` проверяет, является ли число целым, и выводит его без дробной части (например, `{1;2}` вместо `{1.0;2.0}`).
2. Varargs: в классе `Student` используется синтаксис `int... grades`, что позволяет передать любое количество оценок, включая ноль.
3. Работа со ссылками: в задании 2.1 демонстрируется разница между изменением объекта по ссылке и заменой ссылки на новый объект.
4. Поверхностная и глубокая копия: в задании 3.1 показана разница между копированием ссылки на массив и созданием нового массива через `Arrays.copyOf()`.
5. в классе `Point` конструктор без параметров закомментирован, чтобы запретить создание точки без координат.
